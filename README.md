# AlgoInvest&Trade — Projet 7

Ce projet OpenClassrooms consiste à résoudre un problème d’optimisation
d’investissement avec des algorithmes Python.

## Objectif

Sélectionner les actions qui maximisent le bénéfice obtenu après deux ans,
tout en respectant un budget donné.

## Contraintes

- Le budget maximal est de 500 euros.
- Une action ne peut être achetée qu’une seule fois.
- Une action est indivisible.
- Le bénéfice fourni dans les données est un pourcentage du prix de l’action.

## Étapes du projet

1. Développer une solution de force brute.
2. Développer une solution optimisée.
3. Comparer les performances et backtester la solution optimisée.

## Données

Le fichier `data/actions.csv` contient le jeu de données utilisé pour la
solution de force brute.
